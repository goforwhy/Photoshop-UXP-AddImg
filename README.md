# Photoshop-UXP-AddImg 导入器

常用图片快速置入工具，自动读取素材/规范汇总文件夹的子文件夹，点击即可置入当前 Photoshop 文档。

## 使用方法

1. 首次使用点击「初始化」，选择您的素材/规范汇总文件夹
2. 插件会自动读取该文件夹下的所有子文件夹并生成按钮
3. 点击对应的子文件夹按钮，在弹出的文件选择器中选取图片
4. 图片会自动以图层形式置入当前 Photoshop 文档
- 支持「刷新」按钮重新扫描文件夹
- 当初始化没有子文件夹时，将会以选择的文件夹名生成按钮。

## 注意事项

建议将所需素材设置为同一格式，例如全部是PNG，或者全部是JPG，全部是Jpeg。

## 安装
方法一：下载 [cn.gapsun.hanxi.addimg_PS.ccx](./cn.gapsun.hanxi.addimg_PS.ccx)，双击安装（需有 Adobe Creative Cloud）<br>
方法二：下载 file 文件夹，将文件夹放在 `C:\Program Files\Adobe\Adobe Photoshop[你的PS版本]\Plug-ins\`，重启 PS

## 环境要求

Adobe Photoshop 23.0+<br>
